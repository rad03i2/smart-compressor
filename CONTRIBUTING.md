# Contributing

Thank you for improving Smart Compressor. Contributions should keep the project small, dependency-free at runtime, predictable, and careful about archive extraction.

## Development setup

~~~bash
git clone https://github.com/rad03i2/smart-compressor.git
cd smart-compressor
python -m pip install -e .
~~~

## Required validation

Run before opening a pull request:

~~~bash
python -m compileall -q src tests
python -m unittest discover -s tests -v
smart-compressor --version
~~~

## Core principles

### Keep runtime dependencies at zero

The current implementation uses Python's standard library. A new runtime dependency requires a strong technical justification and should not be introduced casually.

### Preserve safe extraction

Changes must not bypass destination-boundary validation or silently accept unsafe TAR member types.

If extraction behavior changes, add security-focused regression tests.

### Preserve explicit overwrite behavior

Existing destinations should not be replaced accidentally. Changes to overwrite semantics require clear tests and documentation.

### Keep format claims accurate

Do not claim support for RAR, 7z, Zstandard, encryption, multipart archives, or resource quotas unless those features are actually implemented and tested.

## Test data

Prefer temporary files and archives generated by the test suite.

Do not commit:

- private archives;
- credentials or secrets;
- large generated archives;
- personal data;
- malicious proof-of-concept payloads without prior maintainer coordination.

## Pull requests

Explain:

1. the problem;
2. the approach;
3. compatibility or security impact;
4. tests performed;
5. documentation updated.

Small, reviewable changes are preferred.
