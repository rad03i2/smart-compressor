# Smart Compressor Brand Guide

Smart Compressor uses a visual system named **Archive Forge**: multiple data streams converge into a compact archive core, then leave as a controlled package. The identity is industrial, technical, and security-aware.

## Personality

- **Industrial** — deliberate, mechanical, predictable.
- **Local-first** — no upload or cloud-service imagery.
- **Safe by design** — archive boundaries and controlled extraction are visible themes.
- **Automation-friendly** — the system feels like infrastructure, not a consumer ZIP app.

## Palette

| Role | Color | Hex |
|---|---|---|
| Base | Deep navy-black | #071116 |
| Surface | Steel teal | #0C1B22 |
| Primary | Electric cyan | #22D3D0 |
| Highlight | Bright aqua | #5AF2E9 |
| Secondary accent | Warm copper | #FF9D42 |
| Main text | Frost white | #F4F7F6 |
| Muted text | Steel gray | #AFC0C4 |

Cyan represents archive structure, verification, and safe boundaries. Copper represents compression pressure and transformation.

## Logo

<code>assets/project-logo.svg</code> depicts a compact archive core with converging compression rails. It does not depend on the project name and remains legible at small sizes.

Avoid generic zipper icons, cloud symbols, or image-compression metaphors. The mark should feel like a data/archive utility.

## Hero cover

<code>assets/project-cover.svg</code> is the main repository identity. It shows multiple document layers converging into a compact archive block.

Do not add fabricated compression percentages or benchmark claims. Actual compression depends on source data and archive format.

## Typography and composition

Use modern system sans-serif fonts such as Inter, Segoe UI, or Arial. Favor strong geometry, compact labels, clear rails, archive blocks, and restrained technical panels.

This identity intentionally avoids:

- the coral/lime creative palette of ImageOptimizer;
- purple AI/knowledge-graph styling;
- OCR scanner imagery.

## Voice

Prefer precise wording:

- “safe extraction” rather than “unhackable extraction”;
- “path traversal protection” rather than “perfect archive security”;
- “standard-library formats” rather than implying RAR/7z support;
- “compression ratio” rather than fixed savings promises;
- “local processing” rather than absolute privacy guarantees.

Accuracy is part of the brand.
