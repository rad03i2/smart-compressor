# Code of Conduct

## Our standard

Smart Compressor welcomes focused bug reports, security improvements, documentation work, tests, and implementation contributions.

Expected behavior includes:

- discuss code and technical decisions respectfully;
- provide reproducible archive examples using non-sensitive data;
- keep security discussions responsible;
- distinguish current behavior from proposed features;
- respect licenses and privacy when sharing sample archives.

Unacceptable behavior includes harassment, threats, discriminatory abuse, deliberate disruption, publishing private data, leaking credentials, or disclosing exploitable security details irresponsibly.

## Scope

This applies to issues, pull requests, reviews, discussions, and other project spaces controlled by the maintainer.

## Enforcement

Maintainers may edit, hide, lock, or remove disruptive content and may restrict participation when necessary.

Security vulnerabilities should follow [SECURITY.md](SECURITY.md) rather than being disclosed in a public issue.
